Three Key Discoveries

This project wasn't just about building a model — it was about auditing every decision along the way.

01

Leakage Detection

SHAP analysis revealed that issue_year and addr_state were causing temporal leakage. Removing them cost 1% AUC but made the model production-ready.

02

Ablation Study

When the model hit a ceiling, we ran controlled experiments (v4 → v5 → v6) to isolate whether max_rounds or learning_rate was the bottleneck.

03

Financial Framework

Beyond AUC, we compute Expected Loss (PD × LGD × EAD) and derive risk-based interest rates — the language banks actually speak.
